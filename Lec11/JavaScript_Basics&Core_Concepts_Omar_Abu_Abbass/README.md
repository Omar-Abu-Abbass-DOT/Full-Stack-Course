# JavaScript Basics & Core Concepts

## Project Overview
A comprehensive collection of JavaScript exercises designed to demonstrate a strong understanding of core programming concepts. This project covers fundamental logic including variable declaration, data type manipulation, arithmetic operations, conditional statements, and iterative loops, showcasing the ability to write clean and functional logic.

## Key Features
* **Output Prediction:** Analysis of JavaScript behavior regarding type coercion (`"5" + 3`), comparison operators (`==` vs `===`), and scope.
* **Code Debugging:** Identifying and fixing common syntax errors and logical mistakes in legacy code snippets.
* **Conditional Logic:** Implementation of real-world decision-making scripts (e.g., Grade System, Positive/Negative Checker).
* **Iterative Control:** Utilization of `for` and `while` loops to handle repetitive tasks and sequence generation.
* **Clean Code Practices:** Organized solution structure with clear comments and formatted output.

## Technologies Used
* **JavaScript (ES6+):** Core language for logic and scripting.
* **Node.js:** Runtime environment for executing JavaScript code outside the browser.
