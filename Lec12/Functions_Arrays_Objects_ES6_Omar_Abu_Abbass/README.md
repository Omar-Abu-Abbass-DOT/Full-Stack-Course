# Functions, Arrays, Objects & ES6 Practice

## Project Overview
A comprehensive collection of JavaScript exercises designed to demonstrate proficiency in advanced core concepts. This project focuses on building reusable functions, manipulating complex data structures (arrays and objects), and applying modern ES6+ syntax to write clean, efficient, and scalable code.

## Key Features
* **Advanced Functions:** Implementation of various function types (declarations, expressions, and ES6 arrow functions) to perform dynamic mathematical and logical operations.
* **Array Manipulation:** Utilizing core array methods (`push`, `filter`, `join`) and custom logic to traverse, extract, and modify data (e.g., finding the middle element, filtering by index and length).
* **Object Operations:** Interacting with key-value pairs, accessing nested properties, and comparing object data (e.g., dynamically comparing ages from different objects).
* **Modern ES6+ Syntax:** Applying template literals, arrow functions, and mathematical object methods (`Math.pow`, `Math.random`) to streamline code readability and performance.
* **Algorithmic Thinking:** Solving practical mathematical and logical problems such as calculating factorials and random binary generation.

## Technologies Used
* **JavaScript (ES6+):** Core language for advanced logic and data structure manipulation.
* **Node.js:** Runtime environment for executing JavaScript code and testing outputs via the console.
